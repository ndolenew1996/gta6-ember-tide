EMBER TIDE is an original open-world crime game set in Port Vela: six districts, five story missions, a wanted system with a police helicopter, a full HUD with a circular minimap, and four staged screenshots of the live game. Every character, place, name, and sound is original — nothing from Rockstar.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 to play. Static files only — no build step, no network.
